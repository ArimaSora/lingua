# 学习者状态靠计算得出，LLM 只做传感器不做记忆

学习者状态存于数据库、由行为数据计算，不让 LLM 通过上下文"记住"用户学习情况。依据：专用知识追踪模型预测学生作答准确率 72–73%，GPT-4o-mini 靠上下文记忆仅 58.6%，且成本相差 600–12400 倍（arXiv:2603.02830）。LLM 的唯一角色是传感器：每轮对话后判分用户产出中目标语块的使用正误，输出结构化记录入库；对话 prompt 仅注入由数据库渲染的 ≤300 token digest。参考先例：Duolingo Birdbrain、LingQ 词汇状态均为独立学生模型。

## Consequences

- 学习日志（判分流、命中率、留存）是一等资产，schema 从第一天按长期研究价值设计。
- 传感器判分错误会污染学习者状态，需要采样人工抽检机制。
