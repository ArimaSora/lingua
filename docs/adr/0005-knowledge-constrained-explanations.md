# 讲解由结构化知识条目约束，三层呈现默认只给第一层

所有语言讲解必须从知识条目出发（RAG/检索增强，防 LLM 编造伪语言学规则），按三层模板呈现：第一层 = 例句 + 一句直觉规律（默认只展示这层）；第二层 = 规律细化与对比；第三层 = 术语与理论。深挖由用户主动触发。依据：无护栏 LLM 家教损害学生独立成绩（Bastani et al. 2025, PNAS）；显性教学效果显著优于隐性（Norris & Ortega 2000；Spada & Tomita 2010），且越复杂的规则越需要显性讲解；专长逆转效应（Kalyuga）表明对新手的详细讲解对进阶者是负担。讲解贴境进行（focus on form），不做系统语法课。语言思维差异采用 Slobin 的 thinking for speaking 框架；避开已证伪材料（强版 Sapir-Whorf、Boroditsky 时间实验）；「形合/意合」标注为教学性概括，并置话题突出 vs 主语突出框架。知识锚资源：Glottolog / WALS / Grambank（均 CC BY 4.0）、English Grammar Profile。
