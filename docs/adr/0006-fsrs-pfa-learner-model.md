# 记忆调度 ts-fsrs + 技能掌握度 PFA

语块级记忆状态用 ts-fsrs（FSRS 算法：KDD 2022 论文背书，Anki 内建调度器，官方 TS 实现，MIT）；技能点级掌握度用 PFA（Performance Factors Analysis, Pavlik 2009），聚合传感器判分流。水平定级用轻量 CAT/C-test 周期校准。阅读侧辅以 LingQ 式查词状态分级与输入时长追踪（Dreaming Spanish 模式）。

## Considered Options

- BKT：不建模遗忘，不适合间隔复习场景，否决。
- DKT：复制研究显示不优于简单模型，且需要大量数据，个人单用户场景不可用，否决。
- SM-2（SuperMemo 2）：已被 FSRS 全面超越，否决。
