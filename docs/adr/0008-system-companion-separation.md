# 系统/角色双联系人分离：工具性归系统，关系性归角色

IM 界面设两个联系人。「系统」扮演软件本身：RSS 订阅管理（含带文字稿的音频 RSS）、内容推送、每日小结与学习性纠错，纯工具文案无人格。「好友角色」只承载关系：闲聊、分享讨论订阅内容、埋伏式复习，纠错仅限对话中影响理解的澄清式询问。依据：角色同时承担教学工具职责会导致人格分裂（朋友发成绩单伤关系）；延迟 prompt 式纠错有效但需要一个不破坏心流与人设的通道（Lyster & Saito 2010；Kamelabad 2026）。主动性机制参照 akashic-agent：候选频繁生成（订阅事件 + 到期语块池）、推送经兴趣过滤，事件驱动不设每日配额；轮询自适应（电量模型）后置。

## Consequences

- RSS 订阅随系统联系人进入 MVP（撤销 ADR-0007 中「RSS 后置」的决定）。
- 预学挂点：系统推送新内容时附带语块预学；角色分享已读内容做讨论与埋伏。
