# 多语言架构：每语言一个专属角色，零基础教学归系统的 Bootstrap 课包

(1) **每个目标语言一个专属好友角色**，系统联系人跨语言共享。理由：角色的人格、语域、文化背景与语言强绑定（如日语敬语体系本身就是核心语域内容）；各语言的母语支架档位、学习者状态相互独立；token 开销不增——每角色仍是一小份 curated facts，只有活跃对话注入。(2) **零基础教学由系统的 Bootstrap 课包承载**：课包 = 策展内容源（高频生存语块、基础句构、A1 分级短文），按序推送，复用「推送 → 预学 → 角色埋伏使用」的既有闭环机制，不加新角色、不加新通道。A1–A2 档角色消息默认附可展开的母语翻译。

## Considered Options

- 加一个「老师」角色：否决——教学的工具性归系统（ADR-0008），角色纯度是关系资产的前提。
- 单一多语角色：否决——语域/敬语等人格要素与语言文化强绑定，且各语言支架档位不同。
- 用户自学外部零基础资源、agent 只做复习：否决——闭环从第一天就需要可理解的内容源。

## Consequences

- 日语书写系统（假名）不做专门交互：假名作为最小语块进 Bootstrap 课包，角色消息附罗马字标注（复用 A1–A2 翻译折叠机制），熟练后标注渐退；输入侧直接用系统日语 IME，仅需 onboarding 提示。
- 语言对为配置项，但学习者状态、关系记忆、支架档位全部按语言隔离存储。
