# 内容难度评估三层管道与解锁队列

系统推送前对内容评估难度，采用三层管道：**L1 主力** = CEFR 分级词表累计覆盖率（EFLLex，CC BY-NC-SA——个人项目可用，商业化需换 NGSL；解锁级 = 首个覆盖率达 95% 的级别，词形还原复用判分管道）；**L2 约束** = 平均句长；**L3 交叉验证** = LLM 粗评三档（A/B/C），不单独定级。

内容按时效性分流：**时效标签**（易腐/常青，系统顺手标注）——易腐 + 太难 → 直接走 LLM 改写版（标注"简化版"附原文链接）或角色转述讨论，**不进解锁队列**；常青 + 太难 → 进**解锁队列**（标注"约 B1 解锁"），难度差转化为进度可视化钩子；队列中易腐条目过期自动清理。信息价值（改写/转述，即时）与原文学习价值（解锁队列，延迟）解耦；兴趣驱动的单位是话题而非单篇文章，同主题新文章会持续从订阅流再来。

依据：覆盖率→理解为连续关系（Schmitt 2011；Kremmel 2023 否定 98% 硬阈值）；FK/ARI 为母语者设计、对二语效度弱（Crossley 2008）；LLM 零样本 CEFR 六级分级准确率仅 64%、连续打分可靠但绝对分级不可靠（Trott & Rivière 2024）；无可信开源 CEFR 分类器。日语前瞻：Waller CC-BY 词表 + kuromoji.js 分词 + jReadability，架构复用。

## Consequences

- LLM 改写真实文章 ≠ AI 生成文章（前者保留真实内容的兴趣价值，仅降难度）——用户已确认接受改写出路。
- 数据积累后升级为 LingQ 式个性化覆盖率（用户个人词库而非通用词表）。
- 附验证约定：4 周自测，话题回应率 ≥50%、埋伏命中率 ≥30%、主观愿意继续用；看什么数据调什么旋钮，不设硬 KPI。
- 判分数据为 append-only 评分日志：抽检纠错 = 标记无效 + 重放重算，同时支持未来算法升级全量重算。
