# 三旋钮分离：内容难度偏好、母语支架档位、语块掌握状态

原设计中内容解锁、母语支架渐退、语域开放都挂在 CEFR 等级上，但自动 CEFR 升级机制缺乏证据基础（单用户 PFA 参数可靠性未验证，研究笔记已注明）。MVP 将三者解耦：

- **内容难度偏好**：由个性化覆盖率驱动（用户已掌握/在学语块对文本的覆盖），不依赖 CEFR 晋升——这是 ADR-0012「数据积累后升级个性化覆盖率」的提前落地。
- **母语支架档位**：用户可随时手动调整（含临时下调），系统可依据事件流提出建议但需用户确认，不自动撤支架。
- **语块掌握状态**：per-item（FSRS）与 per-技能点（PFA），独立演化。

CEFR 等级降级为**展示与手动设置**用途；自动定级暂缓到有验证数据。解锁队列的「约 B1 解锁」标签基于内容自身的难度估计，不依赖用户等级晋升。

个性化覆盖率口径：分母 = 词形还原后的文本 token 总数；语块按 token 区间匹配，重叠去重（长匹配优先）。**已知** = 正式语块中有过 ≥1 次独立产出且当前无未修复失败；其余正式语块为「在学」，不计入已知。展示两个数：已知覆盖（当前可读性）与预学后预计覆盖（已知 + 本文入选语块增量）。未被语块覆盖的词由通用词表层（ADR-0012 L1）估计。冷启动期（观测不足）个性化层不启用，由 Bootstrap 课包 + 通用难度估计兜底。队列标签措辞为「原文难度约 B1」（内容属性），不暗示用户等级是开锁条件。

## Consequences

- 防止「掌握几个熟悉表达就撤掉支架」的级联误判。
- 语域开放节奏跟随支架档位（用户可控），不跟随 CEFR。
