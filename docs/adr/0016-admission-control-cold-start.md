# 准入控制与冷启动路径

候选语块（提取即入池，零成本累积）与正式语块（进入 FSRS 调度，产生复习义务）分离；RSS 更新不自动成为学习任务。

**额度账户制**：每日入账、余额累积、新增正式语块按整数支出。

- **种子期**：每日入账 5。退出条件依据**有效学习历史**而非日历：累计复习完成 ≥ 20 且活跃天数 ≥ 3 才切换——首周只浏览不学习的用户在任何一天开始认真使用都能启动第一条闭环。
- **自适应期**：每日入账 = clamp(近 7 天日均复习完成 × 0.5, 1, 10)。保底每日入账 1：即使完成量为零也不死锁；小数额度经余额累积处理（如日均完成 1 → 每日入账 1，低频用户靠余额持续可新增）。
- **积压保护**：到期积压 > 30 暂停支出（入账继续，但余额上限 15）；积压回落至 ≤ 20 恢复。

**状态转换**：候选 → 正式（入调度）→ 预学完成 → 首次到期 → 此后按 ADR-0013 矩阵。预学完成记 `initial-learning` 事件：**初次学习单独记录，不冒充成功回忆、不更新掌握度**；首次到期 = 预学次日；首次 FSRS 评分来自首次真实回忆事件，不来自预学。

## Consequences

- 零额度死锁不存在：种子期无历史要求，自适应期有保底入账，积压只暂停不扣减。
- 验收用例：首周未学习的用户第 8 天仍能启动第一条闭环；低频学习者的新增额度明确、可持续。
