# 验证约定：4 周自测

MVP 上线后的验证操作手册（issue #14），落实 docs/specs/mvp.md「度量（首日埋点）」的约定：
**4 周自测；话题回应率 ≥50%、命中率 <30% 先调话题生成；看什么数据调什么旋钮。**

数据只来自事件流，不设平行数据源。口径依据：命中率见 ADR-0013，旋钮分离见 ADR-0015。

## 面板与口径

面板由 `GET /api/metrics` 提供（Web 页顶部展示四数 + 掌握曲线），全部由事件流计算：

| 指标 | 口径 | 事件来源 |
|---|---|---|
| 埋伏命中率 | 独立产出 / 埋伏次数 | `ambush-hit`：每次埋伏结算一条，1 = 无近期示范且判对 |
| 话题回应率 | 回应话题 / 发起话题 | `topic-response`：每话题关闭一条，1 = 回应，0 = 超期未回应 |
| 语块掌握曲线 | 近 7 天每日平均 PFA 掌握度（时间序列） | 学习事件按矩阵准入后派生（ADR-0013/0014） |
| 留存 | 次日 / 7 日主动打开率 | `app-open`：每次壳层启动记一条 |

命中率的分子只认**独立产出**（无辅助且判对）：辅助产出、替代正确表达（未产出）、超期未回应都只进分母——命中率低不代表学不会，先看回应率再判读。

## 判读规则：看什么数据，调什么旋钮

- **话题回应率 <50%** → 先调**话题生成**：检查话题钩子是否贴合用户兴趣与共同经历（关系记忆），是否坚持「事件驱动有料才起」而不是硬起话题。
- **埋伏命中率 <30%** → 先调**话题生成**，不要先动记忆算法：
  - 优先排查「不泄题」硬规则（ADR-0013）：话题提示一旦包含目标语块形式或直译，命中率会虚高且失去验证意义；
  - 再看话题是否给了目标语块自然产出的语境——用户总用替代表达完成交际时，话题本身没有制造提取需求。
- **两项都达标** → 旋钮不动，转看掌握曲线：连续下滑时回看预学节奏与内容难度偏好（ADR-0015 的内容旋钮）；母语支架档位永远由用户手动控制，不据指标自动调整。
- **留存（次日/7 日主动打开）**：单人自用阶段反映的是打开习惯而非产品粘性，只记录、不据此调参。

## 节奏

- 自测期 4 周，每周固定记录一次四数（面板数值抄录即可）。
- 每次调整旋钮后，留一整周再评判指标变化，避免把噪声当成效。
